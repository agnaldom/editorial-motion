# Agent instructions

The project-wide instructions for Codex and other coding agents are maintained in [CLAUDE.md](./CLAUDE.md).

Read `CLAUDE.md` completely before making changes. Treat it as the canonical source for:

- project architecture and boundaries;
- Issue → branch → pull request workflow;
- mandatory lint, typecheck, test, and hook quality gates;
- local-only execution and no-deploy policy;
- security, testing, acceptance, and completion standards.

If instructions conflict, follow the higher-priority system/developer/user instructions first, then apply the project rules in `CLAUDE.md`.
